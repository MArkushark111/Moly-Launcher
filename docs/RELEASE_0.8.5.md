# Moly Launcher 0.8.5

- New Rust Edition engine for Minecraft 26.3, with Moly Colour and improved shader and graphics settings.
- Moly checks GitHub for updates on startup and shows release notes before you download an update.
- Mod installs run in a queue. Compatible beta or alpha builds can install when no release is available.
- Pack exports let you choose what to include. Moly also improves imports of packs with Unicode filenames.
- Updated skin previews, startup options, and the Windows installer.

## Windows downloads

- **Moly Launcher** downloads game files and supports Java and Rust Edition instances.
- **Moly Local Launcher** imports supported vanilla versions already on your PC. Open **Local files → Import Minecraft files** to get started. The installer includes no Minecraft game files. Use an installed Java runtime and your own Microsoft account for online play.

Rust Edition uses its own mods and shaders. Java mod JARs require a Java instance. Rust Edition may prepare resources the first time you launch it.
